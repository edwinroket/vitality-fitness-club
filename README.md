# Landing Template

Landing genérica para capturar contactos. El contenido se administra desde `/admin`, por lo que no es necesario editar el código para adaptarla a una nueva marca.

## Qué reemplazar

1. En **Hero y textos**, actualiza la marca, logo, contacto, botones, títulos y descripciones de cada sección.
2. En **Especialidades**, reemplaza los tres servicios de ejemplo por tus productos o servicios.
3. En **Proyectos / Casos**, reemplaza los casos demostrativos, sus imágenes y datos destacados.
4. En **Testimonios** y **Formulario**, añade contenidos y motivos de contacto reales.

Los textos iniciales son deliberadamente neutros y sirven como guía. No incluyen datos de una industria específica.
